
# ERP Industrial Analytics

## Objetivo
Banco de dados demonstrativo de um ERP industrial, utilizando MySQL 8.4.13 e dados fictícios.

## Módulos
- Cadastros
- Vendas
- Compras
- Estoque
- Produção
- Financeiro

## Tabelas previstas
1. clientes
2. fornecedores
3. produtos
4. pedidos_venda
5. itens_pedido_venda
6. pedidos_compra
7. itens_pedido_compra
8. movimentacoes_estoque
9. ordens_producao
10. apontamentos_producao
11. titulos_financeiros

## Regras gerais
- Utilizar chaves primárias e estrangeiras.
- Evitar duplicidade de registros.
- Definir a granularidade de cada tabela.
- Garantir integridade referencial.
- Utilizar dados fictícios.
- Documentar as regras de negócio.
